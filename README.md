# FrontAccounting ERP – Manual Testing Project

## Project Overview
FrontAccounting ERP is a web-based, open-source ERP application designed to help small and medium-sized businesses manage their daily business operations.

## Project Description
This project focuses on manual testing of the FrontAccounting ERP application to verify its functionality, validate user inputs, and identify defects across different modules.

## Application Under Test
- **Application:** FrontAccounting ERP
- **Testing Type:** Manual Software Testing
- **Testing Approach:** Functional Testing
- **Project Documentation:** Test Cases and Defect Reports
- **Application URL:** https://quastechproject.com/projects/frontaccounting/index.php?application=orders

## Modules and Sub-Modules Covered

### 1. Login
- Login functionality
- Validation of login inputs

### 2. Sales
- Sales Quotation Entry
- Sales Order Entry
- Delivery Against Sales Order
- Invoice Against Delivery
- Customer Payment Entry

### 3. Purchase
- Purchase Order Entry
- Outstanding Purchase Orders Maintenance
- Suppliers Invoice
- Payments to Suppliers

### 4. Items & Inventory
- Inventory Location Transfers
- Inventory Item Movements
- Inventory Items Status

## System Workflow

### Sales Workflow
Sales Quotation Entry → Sales Order Entry → Delivery Against Sales Order → Invoice Against Delivery → Customer Payment Entry

### Purchase Workflow
Purchase Order Entry → Outstanding Purchase Orders Maintenance → Suppliers Invoice → Payments to Suppliers

### Items & Inventory
This module manages inventory location transfers, tracks item movements, and monitors inventory item status.

## Testing Activities
- Created and executed manual test cases.
- Tested valid, invalid, and empty inputs.
- Verified expected results against actual results.
- Identified and documented functional defects.
- Assigned severity and priority to defects.
- Recorded test execution results as Pass or Fail.

- Test Scenarios

- Defect Reports
